# Support

For ClambHook support, contact support@swiphtgroup.com.

Official installers, when published, are downloaded only from
`https://clambercloud.com/clambhook/download/`. Purchases, renewals, and license device management are
handled by `store.swiphtgroup.com`.

For license questions, include the purchase email and a redacted license key
prefix only. Do not send full license keys, proxy credentials, private keys, or
profile files unless support explicitly asks for a redacted export.

Include the ClambHook version, platform, architecture, installation source, and
the exact failing action. Treat CI artifacts and locally built packages as
unofficial when describing the installation source.
